One joke about cats, one line, under 200 characters — built for make.fun's "The One-Line Cat Joke That Lands" bounty. `main.ts` writes the joke to `/output/entry.txt` via `MAKEFUN_OUTPUT_DIR` and fails loudly if it ever breaks the gate (not 1–200 characters, not a single line, only white space).

The joke: a setup every cat owner recognises instantly — a dead mouse on the pillow every morning — then a turn nobody sees coming: he is not hunting, he is tipping for room service. Short, no explanation after the punchline, and the kind of line you retell to a friend the same day.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
